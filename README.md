# FPS Manager

FM(풋볼매니저)류 팀 운영 루프 + AI가 대신 싸우는 배틀로얄(4인 팀 × 20팀, 총 80명) FPS 이스포츠 매니지먼트 게임. (2026-08-26 시작)

## 게임 컨셉

플레이어는 직접 총을 쏘지 않습니다. 선수를 영입하고 훈련시켜 경기에 내보내면, AI가 선수 능력치에 따라 랜덤 생성된 지형 위에서 배틀로얄 교전을 치릅니다.

- 핵심 루프: 영입/스카우팅 → 훈련/성장 → 경기 시뮬레이션(관전) → 결과/성장 반영
- 선수 스탯: 에임 / 반응속도 / 클러치 / 포지셔닝 / 팀워크 (현재 클러치·포지셔닝만 구현)
- 관전은 매크로(탑뷰) 시점과 FPS 1인칭 시점을 모두 제공할 예정

## 개발 환경

- Unity 6000.5.8f1
- URP (Universal Render Pipeline)

## 현재 상태

- **배틀로얄 전환 완료(4인 × 20팀, 총 80명)**: 기존 고정 2팀(5v5) 구조를 N팀 구조로 전면 개편. 매치마다 랜덤 생성되는 지형(펄린 노이즈) 위에 20개 팀이 흩어져 스폰되고, 팀이 전멸하면 탈락, 최후 1팀이 남으면 매치 종료
- **자기장(세이프존) 시스템**: PUBG 참고 단계표대로 원이 자동 축소되고, 밖에 있으면 지속 데미지. AI는 자기장 위급도에 따라 확률적으로(이분법 아님) 교전보다 생존 이동을 우선함 — 초반엔 자기장 밖에서도 계속 싸우고, 후반 단계로 갈수록 안으로 들어가려는 비중이 늘어남
- 부위(머리/몸통)별 데미지 시스템, 팀별 고유 색상(20팀 안 겹침), 80명 동시 시뮬레이션을 위한 공간 분할 그리드 + 탐지 스로틀링 성능 최적화
- 관전 카메라: Tab으로 팀 순환, 좌우 화살표로 팀원 순환하며 자유롭게 관전 가능
- AI 전투 행동 결정 레이어: 교전 중엔 정지사격을 우선하고 상황에 따라 좌우 스트레이프도 섞어서 움직이며, 피격당하면 체력·공격자 위치 파악 여부·엄폐물 유무·클러치/포지셔닝 스탯·자기장 위급도에 따라 반격/엄폐 이탈/완전 후퇴/역공격 중 하나를 확률적으로 선택함 — 매번 같은 상황에서도 항상 같은 반응을 하지 않음
- 아직 미구현: 파밍(무기/장비 획득), 에임/반응속도/팀워크 스탯, 매니저 메타 루프(영입/훈련/UI), 매크로 관전 뷰, 리그/대회 구조
