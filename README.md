# FPS Manager

FM(풋볼매니저)류 팀 운영 루프 + AI가 대신 싸우는 5v5 FPS 이스포츠 매니지먼트 게임. (2026-08-26 시작)

## 게임 컨셉

플레이어는 직접 총을 쏘지 않습니다. 선수를 영입하고 훈련시켜 경기에 내보내면, AI가 선수 능력치에 따라 5v5 교전을 대신 치릅니다.

- 핵심 루프: 영입/스카우팅 → 훈련/성장 → 경기 시뮬레이션(관전) → 결과/성장 반영
- 선수 스탯: 에임 / 반응속도 / 클러치 / 포지셔닝 / 팀워크 (현재 클러치·포지셔닝만 구현)
- 관전은 매크로(탑뷰) 시점과 FPS 1인칭 시점을 모두 제공할 예정

## 개발 환경

- Unity 6000.5.8f1
- URP (Universal Render Pipeline)

## 현재 상태

- **5v5 AI 배틀**: 고정 2팀(5v5) 구조로 라운드제 매치 진행, 팀이 전멸하면 라운드 종료 후 자동으로 다음 라운드 시작
- 부위(머리/몸통)별 데미지 시스템, 이동 속도 기반 탄퍼짐(스프레드)
- **AI 전투 행동 결정 레이어**: 교전 중엔 정지사격/좌우 스트레이프/엄폐 이동 세 가지 자세를 상황에 따라 섞어서 쓰고, 피격당하면 체력·공격자 위치 파악 여부·엄폐물 유무·클러치/포지셔닝 스탯에 따라 반격/엄폐 이탈/완전 후퇴/역공격 중 하나를 확률적으로 선택함 — 매번 같은 상황에서도 항상 같은 반응을 하지 않음
- 절차적 엄폐물 배치(맵 중심 기준 180도 대칭), NavMesh 런타임 베이크
- **ML-Agents 실험 진행 중**: 핸드튜닝 AI(`AIBrain`)를 대체할 강화학습 기반 전투 에이전트(`CombatMLAgent`)를 개발 중 — 4차 학습(200만 스텝)까지 완주했지만 명중률 목표(45~50%) 대비 크게 미달(약 10%대), 보상/하이퍼파라미터 추가 조정 후 재학습 예정
- **캐릭터 애니메이션 절차적 방식에서 실제 클립 기반으로 교체 중**: 다리(로코모션)는 Walk/Run 8방향 블렌드 트리로 교체 완료, 팔(사격 자세)은 아직 절차적 회전이 부자연스러운 상태로 튜닝 진행 중
- 아직 미구현: 파밍(무기/장비 획득), 에임/반응속도/팀워크 스탯, 매니저 메타 루프(영입/훈련/UI), 매크로 관전 뷰, 리그/대회 구조
