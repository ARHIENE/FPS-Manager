# FPS Manager

FM(풋볼매니저)류 팀 운영 루프 + AI가 대신 싸우는 5v5 FPS 이스포츠 매니지먼트 게임. (2026-08-26 시작)

## 게임 컨셉

플레이어는 직접 총을 쏘지 않습니다. 선수를 영입하고 훈련시켜 경기에 내보내면, AI가 선수 능력치에 따라 알아서 5v5 FPS 교전을 치릅니다.

- 핵심 루프: 영입/스카우팅 → 훈련/성장 → 경기 시뮬레이션(관전) → 결과/성장 반영
- 선수 스탯: 에임 / 반응속도 / 클러치 / 포지셔닝 / 팀워크 (현재 클러치·포지셔닝만 구현)
- 관전은 매크로(탑뷰) 시점과 FPS 1인칭 시점을 모두 제공할 예정

## 개발 환경

- Unity 6000.5.8f1
- URP (Universal Render Pipeline)

## 현재 상태

- **5v5 AI 배틀 마일스톤 1 구현 완료**: AI 10명이 절차적으로 생성된 맵에서 서로 탐지·이동·교전(레이캐스트 히트스캔)하며 라운드가 진행됨
- 부위(머리/몸통)별 데미지 시스템, 절차적 엄폐물 맵 + NavMesh 기반 이동, 관전 카메라(자유비행 + 플레이어 시점 스냅) 구현
- **AI 전투 행동 결정 레이어 추가**: 교전 중엔 정지사격을 우선하고 상황에 따라 좌우 스트레이프도 섞어서 움직이며, 피격당하면 체력·공격자 위치 파악 여부·엄폐물 유무·클러치/포지셔닝 스탯에 따라 반격/엄폐 이탈/완전 후퇴/역공격 중 하나를 확률적으로 선택함 — 매번 같은 상황에서도 항상 같은 반응을 하지 않음
- 아직 미구현: 에임/반응속도/팀워크 스탯, 매니저 메타 루프(영입/훈련/UI), 매크로 관전 뷰, 리그/대회 구조
